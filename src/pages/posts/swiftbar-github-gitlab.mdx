Quería ver de un vistazo qué PRs tengo que atender. Lo resuelvo
rapidísimo con
[SwiftBar](https://github.com/swiftbar/SwiftBar), un script de bash y `jq`.

![Menú de SwiftBar con mis PRs agrupados por lo que piden de mí](/images/swiftbar-menu.png)

La captura es de mi versión ampliada, con cinco secciones y datos de ejemplo. El script
de abajo es la base, con dos.

## La idea

SwiftBar ejecuta un script cada X tiempo y pinta el stdout en la barra de
menús. Eso es todo.

- El nombre del archivo marca el intervalo: `github.10m.sh` (cada 10 min).
- Lo que va antes del primer `---` sale en la barra. Lo de después, en el menú
desplegable.
- Cada línea acepta parámetros detrás de una barra vertical: `texto | href=URL color=red`.

## Requirements

```bash
brew install --cask swiftbar
brew install gh jq
gh auth login
mkdir -p ~/swiftbar   # elígela como carpeta de plugins al abrir SwiftBar
```

## MVP


```bash
# create file
cat > ~/swiftbar/mvp.5m.sh <<'EOF'
#!/usr/bin/env bash
export PATH="/opt/homebrew/bin:/usr/local/bin:$PATH"
prs=$(gh search prs --author=@me --state=open --json number,title,url,repository)
echo "PRs $(jq length <<<"$prs")"
echo "---"
jq -r '.[] | "\(.repository.name)#\(.number) \(.title | gsub("\\|"; "/")) | href=\(.url)"' <<<"$prs"
EOF

# make it executable
chmod +x ~/swiftbar/mvp.5m.sh

# run it
open -g 'swiftbar://refreshallplugins'
```

Si ves `PRs N` en la barra, funciona. Lo demás es lo mismo con más filtros.

## GitHub

Reviews que te piden + tus PRs con estado de CI, en columnas.

```bash
#!/usr/bin/env bash
# <swiftbar.hideRunInTerminal>true</swiftbar.hideRunInTerminal>
# <swiftbar.hideAbout>true</swiftbar.hideAbout>

# SwiftBar no lee tu .zshrc: sin esto no encuentra gh ni jq.
export PATH="/opt/homebrew/bin:/usr/local/bin:$PATH"
# Un GH_TOKEN exportado pisa el login de gh y puede no ver todos tus repos.
unset GH_TOKEN GITHUB_TOKEN

fragment='
fragment pr on PullRequest {
  number title url
  repository { name }
  commits(last: 1) { nodes { commit { statusCheckRollup { state } } } }
}'

tmp=$(mktemp -d)
trap 'rm -rf "$tmp"' EXIT

# Todas las búsquedas en una query tardan más de los ~10 s que GitHub da a
# GraphQL y vuelven como 502/504. Cada búsqueda va en su propia petición,
# en paralelo, y se reintenta una vez porque el timeout es intermitente.
search() { # nombre filtro
  local query="$fragment query { $1: search(query: \"$2\", type: ISSUE, first: 50) { nodes { ...pr } } }"
  gh api graphql -f query="$query" >"$tmp/$1" 2>/dev/null ||
    gh api graphql -f query="$query" >"$tmp/$1" 2>/dev/null ||
    echo "{\"data\": {\"$1\": {\"nodes\": []}}, \"failed\": [\"$1\"]}" >"$tmp/$1"
}

# user-review-requested y no review-requested, que mete las peticiones a tus equipos.
search review "is:open is:pr archived:false user-review-requested:@me" &
search mine "is:open is:pr archived:false author:@me" &
wait

# Si una búsqueda falla, su sección sale marcada con ! y la otra sigue
# funcionando. Un menú vacío se confunde con "no tengo nada pendiente".
# shellcheck disable=SC2016
jq -rs '
def ci: {"SUCCESS": "✓", "FAILURE": "✗", "ERROR": "✗", "PENDING": "…"}[.commits.nodes[0].commit.statusCheckRollup.state // ""] // "";
def cap($n): if length > $n then .[0:$n - 1] + "…" else . end;
def pad($n): . + ((" " * ($n - length)) // "");
def clean: gsub("\\|"; "/") | gsub("\""; "'\''");
(map(.data) | add) as $d
| (map(.failed // []) | add) as $failed
| [{key: "review", icon: "👀", label: "Review pedida"}, {key: "mine", icon: "📝", label: "Mis PRs"}]
| map(. + {prs: $d[.key].nodes, failed: (.key as $k | $failed | index($k) != null)})
# Nombres largos de repo y títulos de 80 caracteres hacen el menú más ancho
# que la pantalla: el repo se recorta a 24, el título a 40 y el completo va al tooltip.
| map(.prs |= map(. + {ref: ("#\(.number)" as $n | (.repository.name | cap(24 - ($n | length))) + $n),
                         short: (.title | clean | cap(40))}))
# Ancho común a todas las secciones para que las columnas cuadren.
| ([.[].prs[].ref | length] | max // 0) as $wr
| ([.[].prs[].short | length] | max // 0) as $wt
| (map("\(.icon) \(if .failed then "!" else .prs | length end)") | join(" ")),
  (.[] | "---",
    "\(.icon) \(.label)\(if .failed then " (falló) | color=red" else "" end)",
    (.prs[] | "\(.ref | pad($wr))  \(.short | pad($wt))  \(ci) | href=\(.url) tooltip=\"\(.title | clean)\" font=Menlo size=12 symbolize=false"))
' "$tmp"/review "$tmp"/mine
echo "---"
echo "Refresh | refresh=true"
```

- Los filtros son los de la búsqueda de github.com/pulls. Pruébalos ahí primero.
- Mi versión tiene cinco búsquedas, con hilos de review y comentarios. En una
sola query tardaba de 9 a 12 s y GitHub la cortaba a los ~10 s con 502/504. Con
una petición por búsqueda, en paralelo, desaparecen.
- Para alinear columnas hace falta una fuente monoespaciada: `font=Menlo`.
- Para más secciones: `mergeStateStatus` (`DIRTY` = conflictos, `CLEAN` = listo), `reviewDecision`, `isDraft`.

## Chuleta

| Parámetro                           | Qué hace                                          |
| ----------------------------------- | ------------------------------------------------- |
| `href=URL`                          | Abre la URL al hacer clic                         |
| `color=red`                         | Color del texto                                   |
| `length=70`                         | Recorta y pone el título entero en el tooltip     |
| `sfimage=nombre`                    | Icono SF Symbol                                   |
| `symbolize=false`                   | No convierte `:texto:` en iconos                  |
| `alternate=true`                    | Sustituye a la línea anterior con Option pulsado  |
| `bash=ruta param1=x terminal=false` | Ejecuta un script en segundo plano                |
| `refresh=true`                      | Re-ejecuta el plugin al hacer clic                |

- `--` delante de una línea = submenú de la anterior.
- Lo que sale debajo de Refresh en la captura lo añade SwiftBar. Se oculta con los metadatos `swiftbar.hide*`.

Metadatos útiles, en comentarios del script:

```bash
# <swiftbar.refreshOnOpen>true</swiftbar.refreshOnOpen>      # refresca al abrir el menú
# <swiftbar.schedule>*/10 9-19 * * 1-5</swiftbar.schedule>   # cron en vez del nombre
```

## Cuando falla

Pruébalo con el entorno vacío que usa SwiftBar:

```bash
env -i HOME=$HOME PATH=/usr/bin:/bin ~/swiftbar/github.10m.sh
```

- **No aparece:** falta `chmod +x`.
- **`command not found`:** SwiftBar no lee tu `.zshrc`. Pon el `export PATH` arriba.
- **Faltan repos:** hay un `GH_TOKEN` exportado que pisa el login. El `unset` lo arregla.
- **Fila rota:** un título con barra vertical. Para eso está el `gsub`.
- **Datos viejos:** el script falló en silencio. Imprime un título de error y `exit 0`.
- **`GH !` o secciones con `!`:** GraphQL cortó la petición (502/504). Divide la query en varias.
- **Rate limit:** pocas peticiones GraphQL y 5 a 10 min de intervalo.

No metas tokens en los scripts.
