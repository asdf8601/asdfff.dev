Una chuleta para mi yo del futuro: cómo tengo montado tmux y por qué.
Trabajo con muchas sesiones de Claude Code abiertas a la vez, una por
ventana, y casi todo lo que hay aquí existe para no perderlas de vista.

La config vive en mis dotfiles: `~/.dotfiles/macos/home/.tmux.conf`.

## Lo básico

```tmux
set -g prefix C-a
set -g base-index 1
set-option -g status-position top
set-option -g detach-on-destroy off
set -g mouse off
```

- El prefijo es `C-a` y la barra va arriba.
- Navegación estilo vim: `h j k l` para moverse entre panes, `M-h/j/k/l`
  para redimensionar.
- Los splits y las ventanas nuevas abren en el directorio del pane actual
  (`i` o `/` en vertical, `-` en horizontal, `c` ventana nueva).
- `b` vuelve a la última ventana.
- `S` y `V` traen otra ventana como pane.
- `m` enciende o apaga el ratón, que por defecto está apagado.

## Popups

Casi todo lo que no es editar código lo abro en un popup que desaparece
al terminar:

| Tecla | Qué hace                                     |
| ----- | -------------------------------------------- |
| `s`   | elegir sesión con fzf y preview              |
| `P`   | hacer attach a otra sesión                   |
| `Z`   | tmux-sessionizer (sesión por proyecto)       |
| `T`   | `TODO.md` en un split al lado                |
| `O`   | navegar sesiones con tmux-oil.nvim           |
| `D`   | editar los dotfiles, commit y push al cerrar |
| `J`   | buscar tickets de Jira                       |
| `N`   | crear un ticket                              |

## Una ventana por chat de Claude

Aquí está la parte interesante.

### Restaurar cada pane a su chat

tmux-resurrect guarda el comando de cada pane y lo relanza al restaurar. El
problema es que `claude --continue` abre el último chat del directorio, así
que si tengo cinco panes en la misma carpeta, los cinco vuelven al mismo
chat.

La solución es un wrapper, `ccr` (con `alias cc=ccr`), que fija un uuid de
sesión en su propia línea de comandos:

```zsh
#!/bin/zsh
if [[ "$1" == -* ]]; then
  exec claude "$@"
fi

id="$1"
if [[ "$id" =~ '^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$' ]]; then
  shift
else
  exec "$0" "$(uuidgen | tr '[:upper:]' '[:lower:]')" "$@"
fi

session_files=(~/.claude/projects/*/"$id".jsonl(N))
if (( ${#session_files} )); then
  claude --resume "$id" "$@"
else
  claude --session-id "$id" "$@"
fi
```

- Sin argumentos se relanza a sí mismo con un uuid nuevo, así el uuid queda
  en el `argv` del proceso, que es lo que guarda resurrect.
- Ejecuta `claude` como hijo y no con `exec`, porque el proceso de `claude`
  aparece en `ps` sin argumentos.
- Con un uuid que ya existe hace `--resume`. Para anclar un chat viejo a un
  pane: `cc <uuid>`.

En la config de resurrect:

```tmux
set -g @resurrect-processes '~ipython ~ccr "~claude->claude --continue"'
set -g @resurrect-strategy-nvim 'session'
set -g @continuum-restore 'on'
set -g @continuum-save-interval '5'
```

### Estado en la barra

Unos hooks de Claude Code (`UserPromptSubmit`, `Stop`, `Notification`,
`SessionEnd`) llaman a un script, `cc-tmux-state`, que guarda el estado de
cada pane y pinta un icono delante del nombre de la ventana: trabajando,
terminado o pidiendo permiso.

```tmux
setw -g window-status-format " #I #{@cc}#[default]#W "
set-hook -g pane-focus-in 'run-shell -b "$HOME/.local/bin/cc-tmux-state seen #{pane_id}"'
```

El hook `pane-focus-in` marca el pane como visto, así una ventana solo pide
atención hasta que la miras.

Otro hook (`Stop`) renombra la ventana con el título de la sesión, y con
`prefix A` abro un popup con los panes que me esperan: primero los que piden
permiso, luego los turnos terminados que no he mirado.

### Lanzar una sesión nueva

`prefix C` pide un nombre y abre una ventana nueva con Claude en el
directorio actual (script `cc-spawn`).

## Cuidado con `prefix r`

Recargar la config (`source-file`) machaca `status-right`, y tmux-continuum
guarda las sesiones a través de un comando metido en `status-right`. Tras
recargar, el autosave se moría en silencio hasta el siguiente reinicio. Me
enteré cuando un reinicio me devolvió un layout de dos semanas antes.

El arreglo es poner el hook a mano en la config, con la misma ruta absoluta
que usa el plugin:

```tmux
set -g status-right "#($HOME/.tmux/plugins/tmux-continuum/scripts/continuum_save.sh) %Y-%m-%d  %H:%M "
```

Para comprobarlo después de recargar (tiene que dar 1):

```bash
tmux show-option -gv status-right | grep -c continuum_save
```
